# Routes

- `/` → `app/page.tsx` → public home.
- `/sobre-nos` → `app/sobre-nos/page.tsx` → institutional page.
- `/noticias` → `app/noticias/page.tsx` → public news listing.
- `/noticias/[slug]` → `app/noticias/[slug]/page.tsx` → article detail.
- `/admin/login` → CMS login.
- `/admin/posts` → CMS post list/dashboard.
- `/admin/posts/new` → CMS post editor.
- `/admin/posts/[id]` → CMS post editor/update.
- `/admin/settings` → SEO, analytics and site settings.
