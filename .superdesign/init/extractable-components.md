# Extractable components

## Layout
- `AdminShell` — admin sidebar/topbar; props: active navigation state.
- `SiteHeader` — public navigation; props: active route.
- `SiteFooter` — locator/footer.

## Basic
- `Button` — shadcn-style action variants.
- `Card` — panel primitives.
- `Input`, `Textarea`, `Label` — form controls.
- `Badge` — status/category labels.
- `NewsCard` — public content card.
- `PostEditor` — title, slug, category, banner, Quill, publishing and SEO controls.
